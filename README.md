# Procurando

Guía práctica para abogados litigantes. Comienza con la Región de Tarapacá.

## Contenido actual

- Directorio de tribunales de la jurisdicción de la Corte de Apelaciones de Iquique: dirección, teléfono, teléfono de turno y correo.

## Cómo actualizar los datos

Toda la información de tribunales está en `data/tribunales.js`. Para corregir un teléfono o agregar un tribunal, basta con editar ese archivo.

## Aviso

Información referencial. Antes de acudir o enviar documentos, confirma los datos en pjud.cl.
